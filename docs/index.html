Overview

Trim encode/decode helpers for jwt payloads in pipelines. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/trimjwt.git
cd trimjwt
node src/cli.js --help
node --test
